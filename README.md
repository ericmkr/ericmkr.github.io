# Portfolio — mkr

Site statique (HTML/CSS/JS) pour présenter des réalisations UX/UI.

Aperçu des fichiers créés :
- `index.html` — page d'accueil
- `portfolio.html` — liste des projets
- `about.html` — page À propos
- `contact.html` — page de contact
- `submissions.html` — liste des contacts (name, email, message)
- `assets/css/styles.css` — styles responsives
- `assets/js/main.js` — interactions (nav, validation form)
- `assets/img/` — répertoire pour vos images (ajoutez vos fichiers ici)

Pour prévisualiser : ouvrir `index.html` dans un navigateur (double-clic). Pour développement plus avancé, utilisez un serveur local (ex : `python -m http.server 8000` dans le dossier) si vous souhaitez éviter les blocages relatifs aux chemins ou modules.
